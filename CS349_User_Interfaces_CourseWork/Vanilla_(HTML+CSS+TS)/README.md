#### Synopsis
You'll re-implement the Stock application from A2 using vanilla HTML, DOM manipulation and CSS. In addition to re-implementing previous features, this version has more elaborate layout and resizing, allows for multi-select and keyboard shortcuts, and implements undo/redo.

#### Way to compile it:
    npm install
    npm run dev
